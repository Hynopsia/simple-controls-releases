# Simple Controls for MSFS 2024

A faster, clearer controls page for Microsoft Flight Simulator 2024, in the menus and in
flight. This repository holds the downloads and updates, and is where you can report a
problem or suggest something. The source code is not public.

## Download

Get the latest version from **[Releases](https://github.com/Hynopsia/simple-controls-releases/releases/latest)**:
`SimpleControls_<version>.zip` (the installer and a README).

1. Close the sim.
2. Run `SimpleControls_<version>_x64-setup.exe` (no admin rights needed). If Windows says
   "Windows protected your PC", click **More info**, then **Run anyway**.
3. Press **Install**. The app finds MSFS 2024 and your Community folder by itself
   (Microsoft Store, Xbox app and Steam).
4. Start the sim and open **Options > Controls**. In flight: the controls button on the
   toolbar. **How it works** (bottom left) walks you through everything.

Simple Controls updates itself. Before the first install it keeps a copy of all your
control profiles ("Before Simple Controls", kept for good), and it never writes your
profile files: every change goes through the sim, like the sim's own controls page.

## Works great with Simple UI

[Simple UI](https://flightsim.to/addon/116742/simpleui-there-i-fixed-msfs-ui-for-you) rebuilds
the sim's main menu: an aircraft gallery with every livery, favourites, and weather and
time in one bar. The two run side by side, made to go together.

## Something wrong?

1. In the Simple Controls app: **Options > Troubleshooting > Save a report**.
2. **[Open an issue](https://github.com/Hynopsia/simple-controls-releases/issues/new/choose)**
   and attach that file, with what you did and what happened.

The report has what Simple Controls did in the sim and in the app, step by step, with any
errors. It holds folder paths and your device and profile names, nothing else personal.

## Uninstall

Close the sim, then Windows **Settings > Apps > Simple Controls > Uninstall**. The sim's own
controls page is back at its next start; your bindings stay as you left them.
